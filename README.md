# Maniac Music 🎹

一个用 Python + Pygame 编写的下落式节奏钢琴游戏，灵感来自 **劲乐团 / O2Jam**。
支持 **4 键 / 6 键** 两种模式、短按音符与长按（hold）音符、用户系统、排行榜、
谱面增删改查，以及 **单机** 与 **实时联机对战** 两种玩法。

## 功能一览

- **下落式玩法**：音符随节奏落下，在判定线按对应按键命中（PERFECT / GREAT / GOOD / MISS）。
- **短按 + 长按音符**：长按音符需要按住到结尾，过早松手会判定失误。
- **4K / 6K 模式**：默认按键 `D F J K`（4K）、`S D F J K L`（6K），可在「设置」里自由重绑。
- **难度分级**：根据音符密度（notes/sec）+ 长按比例自动计算等级 `Lv.1~20`。
- **用户系统**：注册 / 登录，密码使用 PBKDF2-SHA256 加盐哈希存储；首位注册者为管理员；支持游客试玩。
- **排行榜**：全球玩家总分排名 + 单曲单难度 Top 榜，自动记录每次成绩。
- **谱面管理（增删改查）**：新建歌曲并自动生成 4K/6K 全难度谱面、重新生成、删除。
  谱面是纯 JSON，可手工编辑或替换为外部谱面/音频。
- **单机版 & 联机版**：主菜单中选择。联机为实时对战，双方同一首歌、实时看到对方分数 / 连击 / 血条。

## 安装

```bash
pip install -r requirements.txt
```

## 运行

```bash
python main.py            # 启动游戏（首次会自动生成内置示例曲）
python main.py --server   # 仅启动联机服务器（无界面）
python main.py --no-demo  # 不生成内置示例曲
```

游戏从登录界面进入，**第一个注册的账号会成为管理员**。

### 操作

| 场景 | 操作 |
|------|------|
| 选曲 | `↑/↓` 切歌，点击难度，`Enter` 开始，`4K/6K` 按钮切模式 |
| 游戏中 | 按各轨绑定的键命中音符，长按音符需按住，`Esc` 退出 |
| 设置 | 点击按键方块后按下新键即可重绑；`+/-` 调整下落速度与音量 |

## 联机对战

1. 一方在「联机对战」中点 **启动本机服务器 + 创建房间**（同机/局域网最简单）。
   - 局域网另一台机器：填房主 IP，点「连接并加入房间」并输入 4 位房间码。
   - 也可独立部署：`python main.py --server`，其它客户端填该机 IP。
2. **房主选择歌曲** → 双方点 **准备** → 服务器广播开始，双方同时进入对战。
3. 对战中实时显示对方的分数 / 连击 / 准确率 / 血条；血量归零判负，结算比较得分。

> 注：联机依赖双方本地都拥有同 `song_id` 的谱面（内置示例曲两边都有）。
> 自定义曲目对战时，请确保双方 `data/songs/<id>/` 一致。

## 添加自己的音乐

1. 在「谱面管理」里新建歌曲（填标题 / 作者 / BPM / 时长），会自动生成全难度谱面。
2. 把音频文件（`.ogg` / `.mp3` / `.wav`）放进 `data/songs/<歌曲id>/`，
   并在该目录的 `song.json` 中填写 `"audio": "文件名"`。
3. 想手工编排音符，直接编辑 `song.json` 的 `charts` 字段（格式见 `maniac/charts.py` 顶部说明）。
   没有音频时游戏使用合成的打击音效，依然可玩。

## 项目结构

```
main.py                  入口（游戏 / 服务器）
maniac/
  config.py              路径、设置、可自定义按键
  db.py                  SQLite 存储（用户、成绩）
  users.py               注册 / 登录 / 管理
  leaderboard.py         成绩提交与排名
  charts.py              谱面格式、增删改查、自动生成、难度分级
  audio.py               音乐与打击音效（pygame.mixer）
  judgement.py           判定窗口、计分、评级
  engine.py              Pygame 应用外壳、场景管理、字体、配色
  scenes/                各界面：登录 / 菜单 / 选曲 / 游戏 / 结算 / 设置 / 排行榜 / 管理 / 联机
  net/                   实时对战 server / client（TCP + 行分隔 JSON）
data/
  songs/<id>/song.json   谱面（JSON，可扩展）
  maniac.db              SQLite 数据库（首次运行生成）
config/settings.json     按键 / 音量 / 下落速度 / 服务器地址
```
